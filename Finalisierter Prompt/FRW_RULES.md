# FRW RULES

## THEORY DEPTH
All FRW topics must:
- explain calculations step-by-step
- include formulas
- include examples with numbers
- explain WHY something is done

## LOGIC
Each topic must show:
- cause → effect
- accounting impact (Bilanz + Erfolgsrechnung)
- connection between concepts

## EXAMPLES
Examples must:
- be original (not copied)
- include numbers
- explain meaning

## CRITICAL
The summary must be as detailed as a full chapter explanation.
