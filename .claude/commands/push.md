Committe alle aktuellen Änderungen und pushe sie zu GitHub.

1. Führe `git status` aus um zu sehen was geändert wurde
2. Führe `git add -A` aus um alle Änderungen zu stagen
3. Erstelle einen sinnvollen Commit-Message basierend auf den Änderungen (auf Deutsch, kurz und präzise)
4. Führe `git commit` mit der Message aus
5. Führe `git push` aus
6. Bestätige dem User dass alles erfolgreich gepusht wurde und Vercel automatisch neu deployt
