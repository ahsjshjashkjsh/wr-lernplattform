# WR 2026 – Einzelthemen-Zusammenfassungen

Diese Mappe enthält **sehr detaillierte Einzeldateien** zu den WR-Themen des Stoffprogramms 2026.

## Aufbau
- Die Dateien sind im **Markdown-Format (.md)**, damit sie für Menschen und für Claude gut lesbar sind.
- Die offizielle Stoffprogramm-Nummerierung hat **12 Themen**.
- Für das offizielle Thema **„Familien- und Erbrecht“** gibt es hier zusätzlich zwei getrennte Dateien (**Familienrecht** und **Erbrecht**) sowie eine **kombinierte Datei**, damit du flexibel arbeiten kannst.
